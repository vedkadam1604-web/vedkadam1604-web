# Hi, I'm Vedant Kadam

Data & ML enthusiast building practical, end-to-end projects — from model training to a working app on top of it.

## What I'm building

- **[Heart-Attack-Prediction](https://github.com/vedkadam1604-web/Heart-Attack-Prediction)** — Predicts heart disease risk from clinical data (Random Forest, 82% accuracy) with SHAP explainability, deployed as a Streamlit app.
- **[upi-fraud-anomaly-detection](https://github.com/vedkadam1604-web/upi-fraud-anomaly-detection)** — Credit card & UPI fraud detection combining Gradient Boosting (with SMOTE for class imbalance) and Isolation Forest for anomaly scoring.
- **[SimpLSQL](https://vedkadam1604-web.github.io/SimpLSQL)** — A browser-based SQL learning platform with a live SQLite (WebAssembly) playground, 30 interactive topics, no backend required.
- **[instagram-analytics](https://github.com/vedkadam1604-web/instagram-analytics)** — Python pipeline that exports a 6-sheet Excel workbook and an interactive KPI dashboard with 8 charts.
- **[excel-sales-project](https://github.com/vedkadam1604-web/excel-sales-project)** — Pandas cleaning pipeline that turns a messy retail sales dataset into a professional 5-sheet Excel workbook.
- **[freelancechain-ai](https://github.com/vedkadam1604-web/freelancechain-ai)** — Decentralized compliance and automated escrow platform for freelance engagements under the EU regulatory framework.
